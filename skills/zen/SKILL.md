# Zen

We want simplicity, not complexity. We want code that is easy to read and maintain, not overly defensive or needlessly cautious for its purpose. We want to avoid duplication and use abstractions where they make sense, but be okay with some duplication when it makes the code clearer. We want only the functionality and checks that this codebase needs.
